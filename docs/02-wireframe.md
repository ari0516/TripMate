# 여행 일정 관리 앱 — 와이어프레임 및 UI 구현 명세

## 1. 프로젝트 개요

여행을 생성하고, 여행 기간에 맞춰 날짜별 일정을 관리할 수 있는 여행 일정 관리 앱을 만든다.

핵심 기능:
1. 여행 생성
2. 날짜별 일정 관리
3. 장소 저장 및 관리
4. 장소 영업시간 확인
5. 영업시간/휴무일 경고
6. 지도/블로그 외부 링크
7. 날짜별 가계부
8. 일별 예산 및 예산 사용률 확인

MVP에서는 실제 API나 DB를 사용하지 않고 **더미 데이터(Local State 또는 Mock Data)**를 사용한다.
(단, 실제 구현은 Vercel + Supabase 기반으로 진행 예정)

## 2. 전체 UX 구조

```text
여행 목록
    ↓
여행 선택
    ↓
여행 대시보드
    ├── 일정
    │    ├── 날짜 선택
    │    ├── 일정 추가
    │    ├── 일정 수정
    │    └── 일정 삭제
    │
    ├── 장소
    │    ├── 장소 목록
    │    ├── 장소 추가
    │    ├── 장소 상세
    │    └── 장소 수정
    │
    └── 가계부
         ├── 날짜별 지출
         ├── 지출 추가
         └── 예산 현황
```

모바일 환경에서도 사용하기 편하도록 **반응형 UI**로 제작한다.

## 5. 화면 2 — 여행 생성

**입력 항목**: 여행명, 시작일, 종료일, 일별 기본 예산

```text
┌─────────────────────────────────────────────┐
│ ← 여행 만들기                                │
├─────────────────────────────────────────────┤
│                                             │
│ 새로운 여행을 만들어보세요                  │
│                                             │
│ 여행 이름                                    │
│ ┌─────────────────────────────────────────┐ │
│ │ 도쿄 여행                                │ │
│ └─────────────────────────────────────────┘ │
│                                             │
│ 여행 기간                                    │
│                                             │
│ 시작일                 종료일               │
│ ┌───────────────┐      ┌───────────────┐   │
│ │ 2026.10.12 📅 │  ~   │ 2026.10.16 📅 │   │
│ └───────────────┘      └───────────────┘   │
│                                             │
│ 일별 기본 예산                               │
│ ┌─────────────────────────────────────────┐ │
│ │ 100,000                             원  │ │
│ └─────────────────────────────────────────┘ │
│                                             │
│                    총 5일                    │
│                                             │
│ ┌─────────────────────────────────────────┐ │
│ │              여행 만들기                 │ │
│ └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

**Validation**
```text
여행명 미입력 → "여행명을 입력해주세요."
시작일 > 종료일 → "시작일은 종료일보다 늦을 수 없습니다."
예산 < 0 → "예산은 0원 이상 입력해주세요."
```

**여행 생성 시**: 여행 기간에 맞춰 날짜를 자동 생성하고, 각 날짜에 일별 기본 예산을 적용한다.

예:
```text
2026.10.12 ~ 2026.10.16
DAY 1  10/12
DAY 2  10/13
DAY 3  10/14
DAY 4  10/15
DAY 5  10/16
```

## 8. 화면 5 — 일정 추가

```text
┌─────────────────────────────────────────────┐
│ 일정 추가                                    │
├─────────────────────────────────────────────┤
│                                             │
│ 장소 선택                                    │
│ ┌─────────────────────────────────────────┐ │
│ │ 🔍 장소를 검색하세요                    │ │
│ └─────────────────────────────────────────┘ │
│                                             │
│ 저장된 장소                                 │
│                                             │
│ ○ 센소지                                    │
│   관광지 · 도쿄                              │
│                                             │
│ ○ Blue Bottle Coffee                       │
│   카페 · 시부야                              │
│                                             │
│ 날짜                                         │
│ ┌─────────────────────────────────────────┐ │
│ │ 2026.10.12 📅                            │ │
│ └─────────────────────────────────────────┘ │
│                                             │
│ 시간                                         │
│ ┌───────────────┐  ~  ┌───────────────┐   │
│ │ 15:00         │     │ 16:00         │   │
│ └───────────────┘     └───────────────┘   │
│                                             │
│ ⚠️ 해당 시간은 영업시간이 아닙니다.          │
│                                             │
│ ※ 경고가 있어도 일정을 추가할 수 있습니다.    │
│                                             │
│                  [일정 추가]                 │
└─────────────────────────────────────────────┘
```

**동작**: 장소 + 날짜 + 시간을 입력하면 저장 전에 운영 상태를 확인한다.

- 정상: 🟢 영업중
- 휴무: ⚠️ 해당 날짜는 휴무일입니다.
- 영업시간 외: ⚠️ 해당 시간은 영업시간이 아닙니다.
- 운영시간 없음: ⚠️ 운영시간 정보를 확인할 수 없습니다.

**중요: 경고가 발생해도 일정 추가는 가능해야 한다.**

## 9. 화면 6 — 일정 수정

기존 일정 카드를 클릭하면 수정 화면 또는 Modal을 표시한다.

```text
┌─────────────────────────────┐
│ 일정 수정                    │
│                             │
│ 📍 Blue Bottle Coffee       │
│ 카페                         │
│                             │
│ 날짜                         │
│ [2026.10.12 📅]             │
│                             │
│ 시작 시간      종료 시간     │
│ [15:00]        [16:00]      │
│                             │
│ ⚠️ 해당 시간은 영업시간이    │
│    아닙니다.                 │
│                             │
│ [삭제]             [저장]    │
└─────────────────────────────┘
```

저장하면 변경된 날짜/시간 기준으로 운영 상태를 다시 확인하고 일정 순서를 다시 정렬한다.

삭제 버튼 클릭 시 확인 Modal:
```text
일정을 삭제할까요?
삭제한 일정은 복구할 수 없습니다.
[취소] [삭제]
```

일정 삭제는 Schedule만 삭제하며 Place 데이터는 삭제하지 않는다.

## 13. 운영 상태 UI

장소와 일정에서 운영 상태를 일관되게 표시한다.

```text
🟢 영업중
🔴 영업 종료
🟠 휴무
⚪ 운영시간 정보 없음
```

일정과 운영시간이 충돌하면 경고를 표시한다.
```text
⚠️ 해당 날짜는 휴무일입니다.
⚠️ 해당 시간은 영업시간이 아닙니다.
⚠️ 운영시간 정보를 확인할 수 없습니다.
```

운영 상태 판단 로직은 Place의 `openingHours`, `closedDays`를 기준으로 한다.

## 14. 외부 링크

Place에 다음 URL을 저장할 수 있다: `mapUrl`, `blogUrl`

- 지도 URL이 존재하면 [지도에서 보기] 버튼 표시, 클릭 시 새 탭/외부 브라우저에서 연다.
- 블로그 URL이 존재하면 [블로그 보기] 버튼 표시, 클릭 시 새 탭/외부 브라우저에서 연다.
- URL이 없으면 버튼 자체를 렌더링하지 않는다.

**예산 계산**
```text
일일 예산 = Trip.dailyBudget

잔여 예산 = 일일 예산 - 현재 지출
예산 사용률 = 현재 지출 / 일일 예산 × 100
```

**상태**: 0~79% 기본 / 80~89% 주의 / 90% 이상 경고 — 예산 사용률에 따라 Progress Bar 색상을 변경한다.

## 19. 디자인 방향 (요약 — 상세는 03-design-system.md 참고)

전체적인 UI는 **깔끔하고 현대적인 여행 플래너 앱** 느낌으로 제작한다.

- 과도한 장식은 사용하지 않는다.
- 카드 기반 UI를 사용한다.
- 정보 위계를 명확하게 한다.
- 여행 일정 화면을 가장 중요한 화면으로 디자인한다.
- 모바일에서도 충분히 사용하기 편해야 한다.
- 버튼과 입력창은 터치하기 충분한 크기로 만든다.
- 상태값은 색상 + 텍스트를 함께 사용한다.
- 너무 많은 색상을 사용하지 않는다.
