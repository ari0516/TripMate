# 여행 일정 앱 기능 정의서

## 1. 여행 관리

### 1-1. 여행 생성

**목적**
여행 일정을 관리하기 위한 여행을 생성한다.

**사용자 행동**
- 여행명을 입력한다.
- 여행 시작일과 종료일을 선택한다.
- 일별 기본 예산을 입력한다.
- 여행 생성 버튼을 클릭한다.

**시스템 동작**
- 입력한 정보로 새로운 여행을 생성한다.
- 설정한 여행 기간만큼 날짜별 일정이 생성된다.
- 각 날짜에 기본 예산을 적용한다.

**예외/조건**
- 여행명은 필수 입력값이다.
- 시작일은 종료일보다 늦을 수 없다.
- 예산은 0원 이상이어야 한다.

## 2. 일정 관리

### 2-1. 일정 추가

**목적**
저장된 장소를 특정 날짜와 시간에 여행 일정으로 추가한다.

**사용자 행동**
- 일정 추가 버튼을 클릭한다.
- 장소를 선택한다.
- 날짜와 시간을 선택한다.
- 추가 버튼을 클릭한다.

**시스템 동작**
- 선택한 장소를 해당 날짜의 일정에 추가한다.
- 일정은 시간순으로 정렬한다.
- 장소의 영업시간 및 휴무일을 확인한다.

**예외/조건**
- 휴무일인 경우 휴무일 상태를 표시한다.
- 영업시간 외인 경우 영업시간 외 상태를 표시한다.
- 경고가 발생해도 일정 추가는 가능하다.

### 2-2. 일정 수정

**사용자 행동**
- 기존 일정을 클릭한다.
- 날짜 또는 시간을 변경한다.
- 저장한다.

**시스템 동작**
- 변경된 날짜/시간으로 일정을 업데이트한다.
- 변경된 시간 기준으로 영업 가능 여부를 다시 확인한다.
- 일정 순서를 다시 정렬한다.

### 2-3. 일정 삭제

**사용자 행동**
- 일정 상세 화면에서 삭제 버튼을 클릭한다.
- 삭제 확인 후 삭제한다.

**시스템 동작**
- 해당 일정만 삭제한다.
- 저장된 장소 자체는 삭제하지 않는다.

## 3. 장소 관리

### 3-1. 장소 저장

**목적**
여행 중 방문하고 싶은 장소를 저장한다.

**사용자 행동**
- 장소 추가 버튼을 클릭한다.
- 장소명, 주소, 카테고리, 영업시간, 휴무일을 입력한다.
- 지도 URL 또는 블로그 URL을 입력할 수 있다.
- 저장한다.

**시스템 동작**
- 장소를 저장한다.
- 저장된 장소는 장소 목록에서 확인할 수 있다.
- 장소를 일정에 추가할 수 있다.

**카테고리**
- 맛집
- 카페
- 관광지
- 쇼핑
- 숙소
- 기타

### 3-2. 장소 링크

장소에 외부 링크를 저장할 수 있다.

**지도 URL**
- 네이버 지도 또는 구글 지도 URL 저장
- 지도에서 보기 버튼을 통해 외부 지도 페이지로 이동

**블로그 URL**
- 네이버 블로그 등 리뷰 URL 저장
- 블로그 보기 버튼을 통해 외부 페이지로 이동

**조건**
- URL이 없는 경우 해당 버튼을 표시하지 않는다.

---

## 4. 장소 운영 상태

### 4-1. 영업 상태 확인

장소에 저장된 영업시간과 휴무일을 기준으로 현재 또는 일정 시간의 방문 가능 여부를 표시한다.

**상태**
- 영업중
- 영업 종료
- 휴무
- 영업시간 정보 없음

### 4-2. 일정과 운영시간 충돌

일정에 장소를 추가하거나 일정을 수정할 때 운영시간을 확인한다.

- 휴무일 → "⚠️ 해당 날짜는 휴무일입니다."
- 영업시간 외 → "⚠️ 해당 시간은 영업시간이 아닙니다."
- 정보 없음 → "운영시간 정보를 확인할 수 없습니다."

경고가 발생하더라도 사용자가 일정을 저장할 수 있도록 한다.

## 5. 가계부

### 5-1. 지출 등록

**사용자 행동**
- 지출 추가 버튼을 클릭한다.
- 금액을 입력한다.
- 카테고리를 선택한다.
- 필요하면 메모를 입력한다.
- 저장한다.

**카테고리**
- 식비
- 교통
- 쇼핑
- 관광
- 숙박
- 기타

**시스템 동작**
- 지출을 해당 날짜에 저장한다.
- 해당 날짜의 총 지출을 업데이트한다.
- 남은 예산을 계산한다.

### 5-2. 예산 현황

각 날짜별로 다음 정보를 표시한다.
- 일별 예산
- 현재 지출
- 잔여 예산
- 예산 사용률

**상태**
- 0~79%: 기본 상태
- 80~89%: 주의 상태
- 90% 이상: 경고 상태

예산 사용률에 따라 진행률 바의 색상을 변경한다.

---

## 6. 외부 링크

장소에 저장된 URL을 앱에서 바로 열 수 있도록 한다.

**지도**
- 지도에서 보기 버튼 클릭 시 저장된 지도 URL을 새 창 또는 외부 브라우저에서 연다.

**블로그**
- 블로그 보기 버튼 클릭 시 저장된 블로그 URL을 새 창 또는 외부 브라우저에서 연다.

URL이 존재하지 않는 경우 해당 버튼은 표시하지 않는다.

## 7. 데이터 구조

MVP에서는 우선 더미 데이터를 사용한다.

**Trip**
- id
- name
- startDate
- endDate
- dailyBudget

**Place**
- id
- name
- category
- address
- openingHours
- closedDays
- mapUrl
- blogUrl

**Schedule**
- id
- tripId
- placeId
- date
- startTime
- endTime

**Expense**
- id
- tripId
- date
- amount
- category
- memo

## 8. MVP 개발 우선순위

**Phase 1**
- 여행 생성
- 날짜별 일정
- 장소 저장
- 일정 추가/수정/삭제
- 장소 운영시간 표시

**Phase 2**
- 영업시간/휴무일 경고
- 지도/블로그 링크
- 가계부
- 예산 사용률

**Phase 3**
- 실제 지도 API 연동
- 외부 데이터 자동 수집
- 로그인
- 데이터베이스
- 공유 기능

우선 Phase 1~2까지 더미 데이터로 완성한 후 실제 API 및 데이터베이스를 연결한다.
